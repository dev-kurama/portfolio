      Engineering principles

      1. 01

        Automate the repeatable

        If it has been done by hand twice, it becomes a pipeline.

      2. 02

        Observe before you debug

        Logs, metrics and dashboards first. Guessing is slower.

      3. 03

        Design for failure

        Nodes die and pods restart. The system should barely notice.

      4. 04

        Keep deployments boring

        Zero-touch releases mean nobody holds their breath on release day.

      5. 05

        Scale the system, not the problem

        Find the bottleneck first. Then add capacity.
